# audio/ — Audio Bible（案）

このプロジェクトの「音」の拠り所。世界観から決めた音の方針、Phase 1 の 15 秒動画のキューシート、使うツール、権利の扱いをまとめる。
ここに書いたことは、Ryo が承認するまで**案**。Ryo の決定は `docs/decisions.md` に記録する。

ツールの選定と、生成から書き出しまでの流れの理由：`docs/adr/ADR-0004-audio-generation-and-assembly-pipeline.md`。

## 1. 音の方針（世界観から）

元にした資料：`06_world.md`（九十九年目の家、集まる灯、一本の物語の軸）、
`docs/characters/_common.yaml`（`stage_pattern`、`reveal_pattern`）。

| 方針 | 音での意味 |
|---|---|
| 小さく身近に。映画のように大きくしない | オルゴール・チェレスタ、フェルトピアノ、柔らかい弦の持続音を 1 つ。オーケストラやドラムは使わない |
| 切なさはテンポではなく和音に込める | つかみは体に直接届く音にする。切なさは最後の（短調寄りの）和音に置く |
| Lv0〜Lv1 には声がない（`reveal_pattern`） | Lv3 より前のキャラは、物の音と効果音だけで「聞こえる」。話し声は使わない |
| Lv0 は「気配」（光、揺れ、**音**） | 最初の音は、小さくはっきりした物の音（ガラスや鈴の「チン」、布のこすれ、息） |
| 妖怪のモチーフは通常ルートに出さない | 変化動画に不協和の持続音やホラーの効果音を入れない（妖怪ルート用に取っておく） |

テンポは 60〜80 BPM。歌なし、lo-fi ヒップホップのドラムなし。看板の変化動画には流行りの音源を使わない
（流行りの音源は、後で毎週の開発ログ動画でだけ試す）。

## 2. キューシート — Phase 1 の 15 秒動画

目安は**効果音 7 割・音楽 3 割**。作曲した BGM をまるごと使うことはしない（15 秒では雰囲気を作ることと、それを回収することを両立できない）。

**BGM（`music.reveal15`）は後のフェーズで生成する（2026-10-24 Ryo 決定）。** 最初の版は効果音と字幕だけで作り、
動画の仕様ファイル（`videos/phase1-reveal.yaml`）でも BGM の行はコメントにしてある。

| 時間（秒） | 映像（段階） | キュー ID | 音 |
|---|---|---|---|
| 0.0〜2.0 | Lv0 → Lv1（顔が出る） | `sfx.hook.tink` | 顔が出た瞬間に、明るいガラスの鈴の「チン」を 1 回。まだ音楽なし。ここでスクロールを止める |
| 0.0〜2.0 | （任意） | `sfx.breath.in` | 「チン」の下に、ほとんど聞こえない吸う息 |
| 2.0〜10.0 | Lv1 → Lv2/Lv3（変化が進む） | `music.reveal15`（**後のフェーズ**） | オルゴールのモチーフ（3〜5 音を変化させながら繰り返す）、フェルトピアノが入り、下に柔らかい持続音 |
| 6.0〜9.5 | 変化が速まる | `sfx.shimmer.rise` | 空気感のあるきらめきが上がっていく音、柔らかい風の音 |
| 7.0〜9.0 | 変化が速まる | `sfx.heartbeat.soft` | 柔らかくこもった心音を 2〜3 回 |
| 約 9.7 | （任意）0.3 秒だけ Lv4 を見せる（`teaser_techniques`） | `sfx.glimpse.swell` | 見せ場に向かう、ごく短い逆再生のふくらみ |
| 10.0 | Lv4 の登場 | `sfx.reveal.chime` | 登場のコマに、温かいチャイムの重なり |
| 10.0〜15.0 | Lv4 の静止 | `music.reveal15`（**後のフェーズ**） | 切ない和音 1 つに落ち着き、15.0 秒までにフェードアウト |
| 約 13.5 | Lv4 の静止 | `sfx.breath.wake` | 柔らかく吐く息。キャラが「目覚める」 |

時間は目標。実際の位置は動画の仕様ファイルに書き、最終的な映像のタイミングに合わせて調整する（§5）。
このキューシートは、`PLAN.md` の Phase 1 の絵コンテ案（柱時計）が固まったら合わせて見直す。

## 3. ツール

| 用途 | ツール | 代わり |
|---|---|---|
| 音楽のキュー | ElevenLabs Music（API） | DOVA-SYNDROME（無料、人が作った曲。手作業） |
| 効果音 | ElevenLabs Sound Effects（API） | Kenney.nl の CC0 素材 |
| 組み立て（映像＋音＋字幕） | ffmpeg（スクリプトから実行） | CapCut（手作業） |

使わないもの：Suno / Udio（安定した公開 API がない、歌もの中心、レーベルとの訴訟）、
Remotion（この規模には重い）、流行りの音源（看板の動画には使わない）。

### プロンプトの決まり

- プロンプトは英語で書き、楽器・雰囲気・テンポ・構成を描写する
- **実在のアーティスト・作曲家・ゲーム・作品名をプロンプトに書かない**（作風の模倣と Content ID のリスク）。
  音そのものを描写する（"music box motif, nostalgic, bittersweet"）
- 音楽のキューには必ず "no vocals" を入れる
- 1 つのキューに複数のテイクを生成し、耳で選ぶ。選んだテイクを記録する（§5）

## 4. 権利の扱い（ADR-0002 に従う）

AI 生成の音声も、画像・動画と同じく**出来が良ければそのままリリースに使う**（2026-10-24 Ryo 決定、ADR-0002・ADR-0004）。
リリースに使うと決まるまでは `assets/proto/audio/` に置き、本番素材と区別する。

| 段階 | 音の出どころ | すること |
|---|---|---|
| 試作・宣伝動画（Phase 0〜2） | AI 生成（ElevenLabs の有料プラン）、または CC0 / DOVA の曲 | 投稿するときは必ず「試作版・AI使用」を明記する |
| 市販のリリース（Phase 3 以降） | 出来が良ければ AI 生成のまま。足りなければ作曲家への依頼、または正しくライセンスされた素材 | AI 生成の音声を使う場合は Steam で申告する（2026 年 1 月から音声も対象） |

- ElevenLabs は**有料**プランで生成する（無料プランはクレジット表記が必要で、商用利用できない）。リリースの前には毎回、最新の規約を確かめる
- AI 生成の BGM を市販のゲームに入れる場合、セルフサービスのプランで認められるかを確かめる（ゲームには Enterprise 契約が要るという情報もある）。
  ライセンスの判断なので Ryo に聞く
- AI 生成の音声は著作物として保護されにくい（日米とも、人の創作的な関与が要る）。自分たちの IP として扱わない
- 作曲家に頼む場合の費用の目安：ココナラで短いループ 1 曲 約 5,000〜15,000 円、
  小規模なゲームのサウンドトラック一式を 1 人に頼むと約 750〜6,000 ドル

## 5. ファイルと形式

```
assets/proto/audio/
  cues.yaml              # すべてのキュー：種類、プロンプト、長さ、テイク、承認したテイク、ツール、ライセンス
  takes/<cue-id>/        # 生成した候補（Git 管理外）
  masters/<cue-id>.wav   # 承認したテイク。WAV 44.1 kHz / 16 bit（コミットする）
  game/<cue-id>.ogg|.mp3 # ブラウザの試作用に変換したもの（生成物、Git 管理外）
videos/
  phase1-reveal.yaml     # 動画の仕様：元の映像、キューの位置、字幕
  captions/*.ass         # 日本語・英語の字幕（日本語のファイルに「試作版・AI使用」の表記）
  clips/                 # 元の映像。例：画面の録画（Git 管理外）
out/                     # 書き出した動画（Git 管理外）
```

- **WAV がマスター。** それ以外はすべて変換で作り直せる
- ブラウザの試作：OGG を基本に、MP3 を予備にする。ループは MP3 にしない（エンコーダーの無音の詰め物で、
  ループのつなぎ目にプチッと音が出る）。ループはゼロクロスで切る
- 動画：MP4 の中は AAC
- スマホのブラウザは、最初にタップするまで音を鳴らせない → 試作には BGM を鳴らす前に「タップして始める」画面が要る

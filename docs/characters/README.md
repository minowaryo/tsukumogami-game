# characters/ — Character Bible（案）

付喪神キャラごとの「見た目の約束事」を1キャラ1ファイルの YAML で管理する。
すべて **案**。採用は Ryo が決め、決定は原案側の決定ログ（`docs/original-docs/tsukumogami-game/docs/05_decisions.md`）に記録される。

## 何に使うか

1. **試作画像の生成**：プロンプト・禁止要素・生成設定の唯一の参照元（試作画像は `assets/proto/` に置く想定）
2. **自動QC**：段階ごとの `qc`（人の顔が出るべきか）・禁止タグ・`anchors.palette` で生成画像をふるいにかける
3. **イラストレーターへの発注資料**：`identity` と `anchors` が設定資料のたたき台になる

## 構造

| キー | 内容 |
|---|---|
| `meta` | 版数・状態（draft → approved → locked）・未決定事項 |
| `identity` | 物・時代・出会い・性格・物語の入口・物語での役割・反応ループ（気配 → 気のせい？ → 確かめる → 確信 → 顕現） |
| `reveal` | 段階ごとに明かす人格・物語・残す問い、Lv3 で顔を隠す理由、ぼかし見せの案、妖怪ルートで見える本音の裏側 |
| `anchors` | 全段階で引き継ぐ配色・モチーフ・目・仕草。**ここを変えるとキャラの同一性が崩れる** |
| `stages` | Lv0〜4。`prompt` / `negative_sets`（`_common.yaml` の禁止要素セット）/ `negative`（追加分）/ `must_not`（人が見る禁止事項）/ `qc`（機械判定）/ `approved`（採用画像と seed） |
| `yokai_branch` | 妖怪化の条件、妖怪の姿、戻った後の金継ぎの姿 |

プロンプトの組み立て順は `_common.yaml` の冒頭コメントを参照。

## なぜ見た目は Lv1〜4 の4段階か（案）

段階ごとに受け持つ感情が違うため：驚き（顔）→ 愛着（動き）→ 焦らし（顔を隠した人影）→ ご褒美（顕現）。
焦らしとご褒美はまとめない。3段階に減らすなら Lv1 と Lv2 をまとめる。
デザインが要るのは「物」と「人の姿」の2つだけで、Lv1・2 は物の差分、Lv3 は人の姿の差分なので、段階を増やしても手間は増えにくい。

## 体験の設計（詳細は `_common.yaml` の `reveal_pattern`）

- **顔を見せる＝心を開く**：見た目・人格・物語を同じ段階で少しずつ明かす
- 各段階の終わりに必ず「問い」を一つ残す
- Lv3 で顔を隠すのはキャラ自身の理由（心のわだかまり）にする
- ぼかし見せは Lv4 の本番イラストをゲーム側で加工する。専用の画像は作らない

## 共通の設計ルール（詳細は `_common.yaml` の `stage_pattern`）

- **大人に見える**：Lv3 以降は `adult` の禁止セットを必ず付ける
- **Lv1 の顔**：物にもともとある「2つの丸」か、物が映す・灯す2Dの像で作る。人の顔を描き足さない
- **Lv2 の手足**：物の部品（紐・コード・振り子・刃）で代用する。人の手足は生やさない
- **Lv3 は「その物を通してしか見えない」**：写真の中・鏡越し・後ろ姿・灯りの外。顔は「隠す」（のっぺらぼうは禁止）
- **金継ぎの線は予約済み**：妖怪ルートから戻ったキャラだけに使う
- **妖怪の記号を通常ルートに漏らさない**：一つ目・裂けた口・錆・カビなどは各 Lv2 の `negative` で禁止

## 注意

- プロンプトのタグは SDXL 系アニメモデル（Illustrious / NoobAI 系）を想定した下書き。モデル選定後に効き具合を検証する
- モデル・LoRA ごとに商用利用の可否が違う。試作用途でも採用前に確認する
- Lv4 の性別は全キャラ未決定。`subject_options: [female, male]` で両方生成できるようにしてある

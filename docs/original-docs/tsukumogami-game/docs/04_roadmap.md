# 04 ロードマップ

## 全体の流れ

| フェーズ | 目的 | 目安 |
|---|---|---|
| **Phase 0** | 世界観を深掘りし、キャラ1体で「変化の面白さ」を確かめる | 2〜4週間 |
| Phase 1 | 15秒の擬人化動画をSNSに出して反応を見る | 2〜4週間 |
| Phase 2 | 試作版（3体・部屋ひとつ）をスマホで遊べる形に | 3〜4か月 |
| Phase 3 | イラスト・声を人間に依頼、10体の正式版へ | 6〜9か月 |
| Phase 4 | ローカライズ（英・繁体字・韓）、リリース | — |

Phase 1 で反応が弱ければ、見せ方・キャラ・コンセプトを修正してから次へ進む。

## Phase 1 の準備メモ

- 15秒動画：枕に顔が浮かび、人の姿になるまで

### 15秒動画の作り方（案）
目安：素材が揃っていれば週末1〜2日。手順の中で一番時間がかかるのは画像の一貫性をそろえるところ。

1. **素材画像**：AI画像生成で擬人化5段階の静止画を作る（同じキャラに見えるよう三面図・参照画像を使う）
2. **変化デモページ**：Claude Code に、5枚の画像を順に切り替え、光・揺れ・粒子などの演出を付けたブラウザページを作らせる（`prototype/` に置く）
3. **録画**：スマホの画面収録でそのページを撮る
4. **編集**：CapCut などの無料アプリで、効果音・BGM・字幕（日本語・英語）を付ける
5. **表記**：「試作版・AI使用」を明記

別ルート：
- **AI動画生成**（静止画から動画を作るツール）：手軽だが、キャラの見た目がぶれやすい。演出の参考や補助として使う
- 試作版ができた後は、**実際のプレイ画面の録画**が一番説得力がある
- 日本語と英語で投稿。「試作版・AI使用」を明記
- 見る指標：再生数、保存数、「やりたい」コメント、フォロー増
- 投稿は Ryo が手動で行う

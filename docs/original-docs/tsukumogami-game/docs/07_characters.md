全員、**ひと目で大人に見えるデザイン**が前提。

## 共通ルール（案）

- **依代（よりしろ）方式**：物そのものが人に変わるのではなく、物に宿った魂が人の姿で出てくる。物は物のまま使える。呼べば出てきて、用が済めば物に戻る（ポケモンがボールから出て戻る感覚）。人の姿が見えるのは付喪神と縁を結んだ主人公だけ
  - → **物を使うこと自体がお世話であり触れ合い**（スーツケースで旅に出る＝その子と旅をする、自転車に乗る＝デート）
- **2つの隠しゲージ**：「神様度」（お世話・丁寧な扱いで上がる）と「妖怪度」（放置・雑な扱いで上がる）。条件はゲーム内で明かさない
- **妖怪にも理由がある**：「寂しかった」「待っていた」など。プレイヤーが救いたくなり、元に戻す遊びが生まれる
- **エンディング**：使い続ける道／役目を終えて神様として送り出す道（切ない別れ）／結ばれる道 など
- **壊れかけ・弱っている状態から始まるキャラ**もいる → 直すことで話が進む（下記「修理」参照）

## 隠し条件のパターン（量産用の型）

| 種類 | 例 |
|---|---|
| 時間 | 現実の朝・夜、連続ログイン、同じ時刻に起動 |
| 天気・季節 | 現実の雨の日、夏、正月 |
| 組み合わせ | 急須と湯呑みを並べる、夫婦箸を揃える |
| 言葉 | 褒める、謝る、名前を呼ぶ |
| 手入れ | 日干し、磨く、虫干し、修理 |
| 放置 | 一定期間触らない、雑に扱う（妖怪度↑） |

## 修理の仕組み（案）

- 弱っている・壊れかけの道具を直すと、物語が進む／擬人化が進む
- 象徴的な例：**金継ぎ**（割れた器を漆と金で継ぐ日本の技法。直した跡がかえって美しくなる）。海外でも知られており、「傷ごと大切にする」という作品のテーマそのもの
- 修理ミニゲーム案：金継ぎ、繕い物、ネジ締め、錆落とし、ほこり掃除

### 扱わない方がよいもの（案）

- **トイレなど水回りの一部**：デリケートで、可愛い・ほっこり路線と合わせにくい
- **食べ物・動物**：擬人化後に食べる・出荷する気まずさ。競合（フードファンタジー、ウマ娘等）とも重なる（`01_concept.md` の判断軸参照）

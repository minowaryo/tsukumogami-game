# 03 制作メモ（技術・AIツール・費用・権利）

※費用・相場は2026年10月時点の調査による目安。Claude の見積もりであり確定値ではない。

## 2D か 3D か（未決定）

| | 2D（＋Live2D） | 3D（Unity＋VRoid） |
|---|---|---|
| 可愛さの出しやすさ | ◎ アニメ絵がそのまま活きる | △ トゥーン表現の作り込みが必要 |
| 初心者の難易度 | 低い | 一段高い |
| AIとの相性 | ◎ コードもブラウザで即確認 | ○ コードは書けるが画面操作が多い |
| 費用 | Live2D 1体10〜15万円（個人） | VRoidは無料、作り込みは別途 |

**推奨（案）：** Phase 0 は **2Dのブラウザ試作**（HTML/JS、Phaser など）でコアの面白さ（擬人化の変化・お世話・隠し条件）を確認。気に入れば以下のどちらかへ。
- 2D路線：Godot または Unity ＋ Live2D でスマホアプリ化
- 3D路線：**Unity ＋ VRoid Studio**（pixiv の無料アニメ調3Dキャラ作成ソフト。VRM形式でUnityに持ち込める）＋トゥーンシェーダー
- 折衷：3Dの部屋＋2D Live2Dキャラ

## AIツール（試作用）

### キャラ画像
- **NovelAI / PixAI**：アニメ絵専門。NovelAI は参照画像で同じキャラを保てる
- **Midjourney Niji モード**：一枚絵の美しさは最上位
- **Stable Diffusion 系（Illustrious、NoobAI など）＋キャラ別LoRA**：ガードレールを自分で作る方式。自由度最大、手間大。ComfyUI で運用
- **Google Nano Banana Pro**：三面図・表情差分で一貫性を保ちやすい
- 進め方（案）：方向性を大量に出す → 三面図・表情差分・擬人化各段階を作る → 動かす
- 注意：モデルやLoRAごとに商用利用の可否が違う。使う前に確認

### 小物の3D
- 画像から3Dを作るAI（例：Tencent Hunyuan 3D など）で日用品は作れる。アニメキャラの3D生成はまだ苦手

### コード
- Claude Code に書かせる。Unity の場合は「AIがコード、Ryo が画面で組み立て」の分担

## 費用の目安

### イラスト（1体あたり）
内訳：三面図＋擬人化途中3段階＋人の姿の立ち絵＋表情差分＋チビキャラ
- 手頃な個人クリエイター（ココナラ等）：**約8万円**
  - 参考：全身立ち絵1万円、ミニキャラ7千円、三面図2万円、新規デザイン＋5千〜1万円
- 商業ゲーム経験者：**約20〜30万円**
- フィリピンの英語が通じるイラストレーターも選択肢

### その他
- **Live2D**：イラスト〜動き一括で個人10〜15万円、制作会社30〜40万円（1体）
- **声**：10体で数十万〜150万円程度（セリフ量次第）
- **翻訳**：日英ゲーム翻訳 1ワード10〜25円。5万文字で英語だけ30〜60万円。繁体字・韓国語でさらに倍以上

### 合計
- **試作版（3体・Live2Dなし・声なし）：30〜50万円**
- **10体フル版：300〜800万円**
- → 試作版で反応を見てから段階的に投資

## 期間の目安

**Ryo の想定作業時間は週10〜15時間**（他の副業よりこのゲームを優先）。

| | 週15〜20時間の場合 | **週10〜15時間の場合** |
|---|---|---|
| 試作版（3体・部屋ひとつ） | 3〜4か月 | **4〜5か月** |
| 正式リリース（10体） | 9か月〜1年 | **1年〜1年半** |

### 週15時間の配分例（案）
- ゲーム作り：9〜10時間（Claude Code での開発、試作を触って判断）
- キャラ・素材づくり：3時間（AI画像生成、イラストレーターとのやりとり）
- SNS：1〜2時間（まとめて作業。`08_marketing.md`）

### 時間を節約するポイント
- コードはできるだけ Claude Code に任せ、Ryo は「触って判断する」役に集中
- 最初の規模を小さく（部屋ひとつ、3体）
- 絵は早めに外注し、自分の時間を使わない
- ボトルネックはイラスト（絵柄統一のため1人に依頼すると10体で半年近く）
- iOS ビルドには Mac が必要（Ryo は12月に Apple ラップトップ購入予定）。Android は Windows でも可
- Google Play は新規個人アカウントだと公開前にクローズドテスト期間が必須

## 販路

| 販路 | 位置づけ |
|---|---|
| App Store・Google Play | **メイン**。日本・東アジア・英語圏に一度に届く。日本は iPhone 利用者が多く Apple は外せない |
| Steam | PCで世界に届けるならここ。ヒット後に内容を増やした版を出す先として有力 |
| DMM GAMES | 日本向け特化の選択肢（艦これ・刀剣乱舞もPCブラウザ版から始まった）。利用者はほぼ国内のため優先度低 |
| ブラウザ版・Poki/CrazyGames 等 | ストアを通さず配れる。テスト用途 |
| 代替アプリストア | 日本ではスマホソフトウェア競争促進法の全面施行（2025年12月）で iPhone でも道が開いた。利用者はまだ少ない |

- 手数料：Apple・Google とも年売上100万ドル以下の小規模事業者は15%
- **全年齢向け**。アダルト要素は入れない（ストア審査、タイアップ・コラボ、ほっこりした世界観との衝突を避ける）

## 権利まわり（※専門家に要確認）

- **著作権**：登録不要。絵・文章・音楽・コードは作った時点で保護。アイディアやゲームルールは保護されない
- **商標**：タイトル・ロゴは要登録。日本の特許庁へ、ゲームソフト区分で1区分あたり印紙代合計数万円程度（弁理士費用別）。海外は複数国まとめて出願できる制度あり
- **イラストレーター契約**：「著作権譲渡」「著作者人格権不行使」の条項を必ず入れる
- **AI生成物**：AIだけの絵は著作権で守られにくい → 最終絵は人間に
- タイミング：
  1. タイトル決定時：商標の先行調査、SNSアカウント名・ドメイン確保
  2. 大きく発表する前：商標出願
  3. イラスト発注時：権利条項を契約に

## 体制（誰と組むか）

**基本は個人開発。** 決定権を自分に残し、副業ペースを守るため。

| 区分 | 方針 |
|---|---|
| 共同開発者・共同創業者 | 最初は避ける（利益配分・権利・決定権で揉めやすい） |
| 企業・パブリッシャー・出資者 | 最初は避ける（契約・納期・報告義務。実績前は条件が不利） |
| 外注（イラスト・声優など） | OK。成果物と権利を受け取る関係なので決定権は残る |
| 感想・テスト協力者 | OK。知り合いのゲーム好き、SNSのフォロワーなど |

- 人を巻き込むのは、動画や試作版の反応が良く「伸びる」と見えてから。その段階なら条件交渉もしやすく、必要な役割も明確
- **勤務先の就業規則で副業の扱いを確認する**
- **開発は私物のPC・業務時間外で行う**（会社の設備・時間で作ったものが会社の権利と見なされる契約もあるため）

## アイデアのレビュー方法

1. **AIレビュー（無料）**：役割を指定して別々にレビュー（例：萌えゲームを10年遊ぶ日本人プレイヤー、海外の乙女ゲームファン、辛口ゲームプランナー、パブリッシャー）。「失敗する理由を10個」のように欠点探しを依頼。複数のAIで比較
2. **ターゲットの生の声（ほぼ無料・最重要）**：SNSに擬人化動画を出す、知り合いのゲーム好きに見せる、個人開発者コミュニティ（#ゲーム制作、#indiedev 等）
3. **プロのレビュー（数千〜数万円）**：ココナラ・MENTA 等のゲームプランナーによる企画書レビュー。試作版ができたら BitSummit、東京ゲームショウのインディーエリア等も検討

順番：AIで穴を潰す → 動画で反応を見る → 反応が良ければプロに企画書を見てもらう

## 事前検討事項

| # | 項目 | いつ決める・確認するか |
|---|---|---|
| 1 | ゴールと撤退ライン | **Phase 0 中（今すぐ）** |
| 2 | マニラ在住ならではの確認（税金・在留資格・事業形態） | Phase 2 の終わり頃（専門家に相談） |
| 3 | ストアの開発者アカウント | Phase 2 の終わり頃 |
| 4 | 課金まわりの法律 | 課金設計を決めるとき／リリース前 |
| 5 | リリース後の運営負担 | 正式版の規模を決めるとき |

### 1. ゴールと撤退ライン（最重要）
- **成功の基準を先に数字で決める**（例：Phase 1 の動画で再生〇回・保存〇件、リリース後に月〇万円）
- **撤退・方向転換の基準も決める**：予算の上限、期間の上限、「ここまでやって反応がなければ見直す」ライン
- **時間配分と優先順位**：週に何時間このゲームに使うか。他の副業構想との優先順位も決める
- 決めた内容は `05_decisions.md` に記録

### 2. マニラ在住ならではの確認事項（※専門家に要確認）
- **税金**：日本とフィリピンのどちらで課税されるか、ストア売上をどの国の口座で受け取るか → 税理士に一度相談
- **在留資格**：フィリピンでの就労条件の範囲で副業収入を得てよいか
- **事業形態**：個人／屋号／法人のどれで出すか

### 3. ストアの開発者アカウント
- Apple は年額、Google は初回のみの登録費が必要
- 個人で課金ありアプリを出すと、ストア上に本名や住所が表示される場合がある → 気になるなら法人化やバーチャルオフィスを検討

### 4. 課金まわりの法律（※専門家に要確認）
- ガチャ的要素を入れる場合、国によって確率表示義務や規制がある（韓国など）
- ゲーム内通貨（前払式の通貨）の未使用残高が一定額を超えると、日本では届け出が必要になる制度がある
- プライバシーポリシー、年齢レーティング、広告の同意画面（iOS のトラッキング許可など）が必要

### 5. リリース後の運営負担
- バグ報告、レビュー対応、OS アップデート対応、イベント追加など、出した後も手間が続く
- 「月にどれくらい保守に時間を使えるか」を見積もり、正式版の規模を決める材料にする

## ストア・規約上の注意

- キャラは全員ひと目で大人に見えるデザイン
- 結婚はほっこり路線に留める（年齢制限・審査対策）
- 実在の薬物等は扱わない
- Steam に出す場合は AI 生成素材の申告が必要

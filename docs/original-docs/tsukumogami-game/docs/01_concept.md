# 01 コンセプト・世界観

## 一言で

**「物を大切にすると、付喪神が宿って、少しずつ人の姿になる。」**

日用品を撫でたり、手入れしたりしていくと、物に顔が浮かび、手が生え、やがて可愛いキャラクターになる。最後は結ばれる（結婚）エンドもある。

## 世界観の土台（Ryo の発想）

- **八百万の神**：あらゆる物に神が宿るという日本の考え方
- **付喪神**：長く大切に使われた道具に魂が宿るという言い伝え
- **「もったいない」「物を大切にする」日本人らしさ** を作品の芯に置く
- **ポケモン / たまごっち / デジモン的な快感**：小さなものから命が飛び出す・少しずつ進化する。それを「一番身近な日用品」に置き換える

## ゲームの核となる仕組み

### 1. 段階的な擬人化（最大の見せ場）
例：枕
1. ただの枕
2. ふと顔がポロッと浮かぶ
3. 手足・髪などが少しずつ現れる
4. 人に近い姿
5. 完全な人の姿（可愛いキャラ）

→ **変化の瞬間** が「爽快感」の役割を担う。演出（光・音・揺れ・ボイス）を最も作り込む場所。SNS動画映えもここ。

### 2. お世話（触れ合い）で進む
- スマホのタッチ操作：撫でる、つつく、抱きしめる（長押し）など
- 物ごとの手入れ：枕なら日干し、いい匂いの柔軟剤で洗う、など
- 擬人化の段階ごとに反応が変わる

### 3. 隠し条件探し
- どの行動で擬人化が進むかは明示しない。意外な行動が条件になっている
- プレイヤー同士で「この条件見つけた」と情報交換したくなる設計（ポケモンの隠れた進化条件のイメージ）

### 4. 現実時間との連動（ラブプラス的）
- 1日1回のお世話、朝と夜で反応が違う、など
- 継続率と広告・課金の相性が良い

### 5. 神様ルート / 妖怪ルートの分岐（案）
付喪神の言い伝えには「粗末にされた道具は恨みを持った妖怪になる」という面もある。
- 大切にする → 可愛い付喪神（神様）として擬人化
- 放っておく・雑に扱う → ちょっと怖い妖怪の姿へ
- Ryo のホラー好き・「怖いけど可愛い」路線と自然につながる
- 妖怪ルートにも魅力を持たせ、「あえて見たい」遊び方を生む

### 6. 対話
- 最初は **選択肢式**。AIによる自由会話は後から追加を検討（API費用・発言制御の課題があるため）

## 世界観を作り込むときの柱（案）

1. **舞台**：例）古い家を受け継いだ主人公が、眠っていた道具たちと暮らし始める
2. **ルール**：何をすると神様に近づき、何をすると妖怪に近づくか
3. **キャラごとの物語**：その道具が誰にどう使われてきたか。前の持ち主の思い出が、キャラの性格や悩みになる
4. **ゴール**：人の姿になって結ばれる、神様として送り出す、妖怪として…など複数エンド

## ゲームの方向性と見せ方（未決定・ブレスト対象）

大枠（付喪神・段階的擬人化・スマホ）は決まっているが、**どういうジャンルの遊びとして見せるか**はまだ決めていない。Phase 0 で Claude Code とブレインストーミングして決める。

### 方向性の候補（案）
- **A. 触れ合い特化型**：ラブプラス的。画面の中の付喪神と1対1で触れ合う。シンプルで作りやすい
- **B. コージーゲーム型**：あつ森・牧場物語的。受け継いだ古民家を少しずつ修復・片付けしながら、道具（付喪神）を育てる。部屋を直すと新しい道具に出会える。ゆるく毎日遊べる
  - 参考：Stardew Valley（ほぼ一人で開発され世界的ヒット）
  - 規模は小さく：家ひとつ・部屋2〜3・付喪神3体・1日5分から
- **C. ホラー寄り型**：妖怪ルートを前面に。「怖いけど可愛い」
- **D. 上記の組み合わせ**：例）基本はB、粗末にした道具だけCの要素が出る

### ブレストで詰めたい問い
- 最初の15秒動画で、何を見せれば「やりたい」と思わせられるか
- 1日のプレイの流れ（何分、何をする）
- 擬人化以外の進行の手応え（家の修復、コレクション等）
- どこで課金したくなるか（雰囲気を壊さない形で）

### 舞台・擬人化する対象を選ぶ5つの判断軸
没入感のある設定かどうかを、感覚だけでなく以下の物差しで比べる。

1. **ルールに無理がないか**：「なぜ人の姿になるのか」が一言で説明できるか。付喪神＝長く大切に使われた道具に魂が宿る、なので「道具」とは相性が完璧。作物や動物は別の理由づけが必要
2. **気まずさがないか**：作物を擬人化後に食べる、動物を擬人化後に出荷する、などは生々しい。描写を避けても遊ぶ人の頭に浮かぶ
3. **現実の自分とつながるか**：道具なら「自分の家の枕にも魂があるかも」と現実の物の見え方が変わる。SNSで「うちの子（愛用品）」を投稿したくなる＝拡散装置になる
4. **競合とかぶらないか**：動物の擬人化はウマ娘・けものフレンズ、食べ物の擬人化はフードファンタジー等の先行作が大きい。日常の道具は比較的空いている
5. **作れる規模か**：畑・牧場・動物まで入れると制作物が一気に増える

### なぜ「物（道具）」に絞るのか（理由のまとめ）
- もともとの発想（枕や箸を大切にすると擬人化する）が「物」から始まっている
- 人参（作物）や牛（動物）と比べ、上の5つの判断軸すべてで道具が有利
- 後から加わった利点：
  - **依代方式**で物は物のまま使え、「使うこと＝触れ合い」になる
  - **「もったいない」「物を大切にする」**という日本らしいテーマが作品の芯になり、海外にも伝わりやすい
- 作物・動物は捨てたのではなく、**擬人化するのは道具、畑・茶畑などは遊びの舞台**として使う整理

### 判断軸に照らした現時点の有力案（案・未決定）
- **擬人化するのは「道具」に絞り、畑や牧場は「遊びの舞台」として使う**
- 例：**茶畑のある古民家**
  - 茶葉を育てて、摘んで、淹れる（牧場物語的な育てる楽しさ）
  - 使う急須・茶筅・湯呑み・茶摘みかごが、大切に使うほど付喪神になる
  - 擬人化するのは道具なので食べる気まずさがない。「丁寧にお茶を淹れる」行為が道具を大切にすることになる
  - 季節ごとに新しい道具が増える（春：茶摘み、夏：風鈴、冬：こたつ など）
- 他の舞台候補（ブレストで比較）：古民家、茶畑、喫茶店、骨董屋 など
- Ryo の当初の発想（人参を育てる、牛を大切に育てる）は判断軸1・2・4に課題があるため、舞台側の要素として活かす方向で検討

### 課金の考え方（案）
- 見た目系（内装・家具・着せ替え）を柱に。強さに関係しない課金
- 特別なお世話アイテム（高級柔軟剤など）は「早く進む・特別な反応」程度。課金必須の擬人化にはしない
- 季節限定の付喪神の追加パック（風鈴、こたつ など）
- 月額パス、任意視聴の広告

### 組み合わせの有力案（案）
- **修理屋 × 修復 × 触れ合い（4＋2＋5）**：客の思い出の物を気持ちいい修復作業で直すと付喪神が目覚め、仲良くなる。金継ぎが看板の遊びに。世界観・動画映え・物語の追加しやすさのバランスが良い（Claude の推し）

## 面白さの優先順位と探索の設計（案）

### 優先順位
1. **変化の瞬間**（見せ場・SNSに出る部分）
2. **キャラとの関係**（物語と触れ合い）
3. **発見**（「この子にも魂が宿りそう」と気づく）
4. **隠し条件**（やり込み・情報交換）

- スマホは最初の数分で面白さが伝わらないと離脱される → **最初のプレイで1体目の顔が浮かぶところまで必ず見せる**
- 探索・隠し条件は脇役。時間をかけさせすぎない

### 付喪神候補の探し方：「気配」を見せる
- 完全に隠さず、ヒントを見せて「見つけた！」と思わせる（Pokémon GO の揺れる草むら、あつ森の地面のヒビの感覚）
- 魂が宿りかけの物はかすかに光る・ときどき小さく動く
- （チビキャラ案の場合）気配のある物の前で立ち止まって振り向く
- 最初の数体はわかりやすく、蔵の奥や季節限定は見つけにくく

### 隠し条件：「表」と「裏」に分ける
- **表の条件**：手入れする・使うなど、普通にやれば進む。誰も詰まらない
- **裏の条件**：特別な物語・特別な姿・妖怪ルート分岐。見つけたらご褒美、見つけなくても進める
- キャラのセリフにヒントを混ぜる（例：傘「最近、雨の音を聞いてないな…」）
- 隠し条件は「足止め」ではなく「ご褒美」

### スマホの機能の使い方
- **メインはタッチ**（撫でる・つつく・長押しで抱きしめる）。他は「たまにある驚き」として少しずつ
- 時計（朝夜・連続ログイン）、天気（位置情報から取得）、マイク（息で熱いお茶を冷ます・風鈴を鳴らす）、振る（鈴・目覚まし）、カメラ（将来の写真連動）
- 注意：スマホには周囲の気温センサーは基本的にない。気温は位置情報から地域の気温を取得する

## 物と人の姿の整合性：依代（よりしろ）方式（案）

- 物そのものが人に変わるのではなく、**物に宿った魂が人の姿で出てくる**（神道の依代＝神が宿る器の考え方）
- 物は物のまま使える。呼べば出てきて、用が済めば戻る
- → **物を使うこと自体がお世話であり触れ合い**。人の姿になったら物として使えなくなる問題を解消
- エンディングで「役目を終えて神様として送り出す」道も用意できる
- 詳細は `07_characters.md`

## 物語パート（テキスト・チャット形式）（案）

- 売れている可愛いキャラのゲームはほぼ物語パートを持つ（ブルアカのメインストーリー＋モモトーク、ウマ娘の育成ストーリー、ラブプラスの会話）
- 二本柱：**触れ合いで育てて、物語で好きになる**
  - 毎日の遊び：お世話・触れ合い（短く何度でも）
  - ご褒美：擬人化が1段階進むごとにテキストの物語が1話開く（前の持ち主の記憶、その子の悩み）＝恋愛パート
  - チャット機能：付喪神からメッセージが届く（例：傘から「今日、雨だよ。連れてってくれる？」）。現実の天気連動とつながる
- ボイスは全セリフではなく要所の一言から（翻訳費・収録費はテキスト量に比例するため、1話は短め）

## 何が新しいか（2026-10-17 時点の整理）

### 付喪神を扱った先行作品
- **もののがたり 〜異界ノ契〜**（ジャンプ原作のスマホ3DバトルRPG。付喪神を見つけて討伐）
- **刀剣乱舞**（刀の付喪神を集めて戦う）
- **99 Spirits**（Steam、付喪神と戦うバトルRPG）
- **Date Everything!**（物と恋愛し実体化。付喪神ではなく魔法のメガネ）
- → 付喪神作品の多くは「戦う・集める」方向。「日用品を大切にお世話して少しずつ人の姿になる、ほっこりした暮らしのゲーム」は調べた範囲では見当たらない
- 出典：https://news.denfaminicogamer.jp/news/250414q / https://apps.apple.com/jp/app/id6451478360 / https://store.steampowered.com/app/262300

### 新しさのポイント
1. **戦わない付喪神**：暮らしの中で育てる。ジャンルの空白
2. **変化の過程が主役**：顔が浮かび、手が生え、人になる。15秒動画にそのままなる
3. **使うこと自体が触れ合い**：依代方式で物と人の姿が矛盾しない
4. **現実とつながる**：天気・時間で反応が変わる。「うちの子」をSNSに投稿したくなる
5. **怖さが優しさにつながる**：妖怪ルートは放っておいた物への罪悪感と救いたい気持ちを生む
   - 育て方で姿が変わる仕組み自体はたまごっち・デジモンにある。付喪神の伝承と掛け合わせ、妖怪を救える形で擬人化・恋愛・育成に組み込むのが新しい
6. **金継ぎ・修理**：傷ごと大切にする。作品テーマの象徴になりうる

※新しさは題材そのものではなく**組み合わせと体験**。最終的には最初の見た目と変化の瞬間の気持ちよさで決まる

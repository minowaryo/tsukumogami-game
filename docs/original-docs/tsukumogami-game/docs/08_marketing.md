# 08 見てもらう仕組み（マーケティング）

## 基本方針：作りながら見せる

- 「ゲームの前に宣伝だけする」のではなく、**作りながら同時に途中経過を見せる**
- 理由：
  1. **需要の確認**：何か月も作ってから「刺さらなかった」と分かるのが一番の損。コンセプト動画なら数週間で方向性が見える
  2. **リリース時のファンづくり**：個人開発の最大の難関は、出した瞬間に誰にも気づかれないこと
- 見せる素材はゲーム作りの中から自然に出る。宣伝だけに何か月も使わない。主役はゲーム作り

流れ：Phase 0 で試作と擬人化画像 → Phase 1 で15秒動画を出して反応を見る → Phase 2 以降は作りながら週1回程度開発の様子を出す

## フォロワーが少なくても大丈夫な理由

- TikTok、YouTube ショート、X の「おすすめ」タブは、フォローしていない人にも反応の良い投稿を表示する
- フォロワー0でも動画が大きく伸びることは珍しくない
- 勝負は「アカウントの強さ」より「**最初の1〜2秒で指を止めさせられるか**」

## 具体的にやること

- **ゲーム専用アカウントを作る**（個人アカウントではなく作品名で）。X、TikTok、YouTube ショート、Instagram リールに同じ動画を出す
  - 日本は X が強い、東南アジア・欧米は TikTok が強い
- **冒頭で惹きつける**：縦長動画、最初の1秒で「枕に顔が浮かぶ」。説明は後回し。「あなたの家の物にも魂が宿っているかも？」のような問いかけ
- **開発の様子を定期的に**：週1回など一定ペース。「キャラ案AとBどっちがいい？」の投票はファン作りに有効
- **ハッシュタグ・コミュニティ**：#個人開発 #ゲーム制作 #インディーゲーム #indiedev、毎週土曜の #screenshotsaturday。Reddit のインディー・コージーゲーム系（宣伝ルールに注意）
- **投稿時間**：マニラは日本と1時間差。日本の夜・欧米の夕方に合わせて予約投稿
- 「試作版・AI使用」を明記

## ある程度形になったら

- **小さめの配信者・VTuber に試作版を送る**（ホラー・コージーゲームを扱う、数千〜数万人規模）
- **ゲームメディアに紹介依頼**（AUTOMATON、4Gamer など）
- **事前登録・ウィッシュリスト**を用意（Google Play の事前登録など）
- **インディーゲームのコンテスト・イベントに応募**（入賞・出展自体が宣伝）

## 見る指標

- 再生数だけでなく、**保存数・シェア数・「やりたい」コメント**
- ほとんどの投稿は伸びない（10本中1本当たれば良いほう）。伸びなかった投稿から「どの見せ方が反応されたか」を学ぶ

## 週の作業時間内に収めるコツ（SNSは週1〜2時間）

- 開発中に画面収録をこまめに撮り、週1回まとめて編集
- 同じ動画を各SNSで使い回す
- 予約投稿で1週間分を一度にセット

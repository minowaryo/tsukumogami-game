# 09 市場戦略

## 方針（Ryo の決定）

**日本だけに閉じず、東南アジアも最初から狙う。** ただし役割を分ける。

| 市場 | 役割 | 内容 |
|---|---|---|
| **日本** | 収益と評価の柱 | 可愛いキャラへの課金が最も多い市場。Ryo の「本気の萌え」の感性が最も活きる。品質の基準は日本に合わせる |
| **東南アジア** | 検証と規模 | 遊ぶ人の数が多く、広告収益と口コミの広がりを担う。**先行配信（ソフトローンチ）の場**として使う |
| 台湾・韓国・香港 | 追加の課金市場 | アニメ・萌え文化が共通。繁体字・韓国語で展開 |
| 英語圏（欧米） | 英語版で同時にカバー | 英語版があれば追加の手間は小さい |
| 中国本土 | 後回し | 版号（配信許可）が必要。当たってから現地パブリッシャーと組む |

## 展開の流れ（案）

1. **フィリピンなど英語圏の東南アジアで先行配信（ソフトローンチ）**
   - 英語が通じ、広告費が安く、反応を測りやすい。業界でも先行配信先としてよく選ばれる
   - 継続率・課金率・どこで離脱するかを確かめて改善
   - **マニラ在住の強み**：現地のフィリピンの人に直接触ってもらえる
2. 改善してから **日本で本番リリース**
3. 反応次第で **タイ語・インドネシア語・ベトナム語** を追加、繁体字・韓国語も

## 今のうちに設計に入れておくこと

- **誰でも伝わる見せ方を軸に**：「付喪神」という言葉に頼らず、「大切にした物に魂が宿る」「放っておくと寂しくなる」を前面に。日本的な要素は味付け
- **国を問わず伝わる要素で引きつける**：可愛さ、ちょっとした怖さ、泣ける物語
- **軽さ**：安い端末でも動く（2D＋Live2D が有利）
- **収益設計**：広告と安い課金でも成り立つ形（東南アジアは一人あたり課金額が低い）
- **言語**：最初から日本語と英語の二言語
- **宗教への配慮**：インドネシア・マレーシアはイスラム教徒が多い。神様や儀式の描き方に注意

## 東南アジア市場のデータ

- 2025年第1四半期のモバイルゲームのダウンロード数は19.3億件で**世界2位**。インドネシア8.7億件、フィリピン3.66億件、ベトナム3.29億件
- 同時期のアプリ内課金収益は6.25億ドルで**世界7位**。課金はタイが中心（1.62億ドル）
- 年間の一人あたり平均収益は約18.8ドル（2024年）
- 東南アジアのゲーマーの**87%が何らかの現地語対応を希望**。重要なのはタイ語・ベトナム語・インドネシア語（タイ語は単語間スペースなし、ベトナム語は記号対応、インドネシア語は英語より文字列が長くなる → UI設計で考慮）
- 約3分の1が**アプリ外での支払い**（チャージ、電子財布、キャリア決済など）を好む
- インドネシアは広告収益向き

## 感性の相性（一般的な傾向としての見立て）

- **物や家に魂が宿る考え方がもともとある**：タイの家・土地の守り神の祠、フィリピンやインドネシアの精霊信仰 → 付喪神・座敷わらしは感覚的に伝わりやすい
- **ホラーが大人気**：タイ・インドネシア・フィリピンはホラー映画が強い → 妖怪ルートが強いフックに
- **泣ける物語が好まれる**：フィリピンの感情に訴えるドラマ・恋愛もの。インドネシアのスタジオによる切ない物語の A Space for the Unbound も高評価
- **アニメ調の絵柄**は地域全体で受け入れられている

## 日本発・日本風ヒットの海外での実態

- **ウマ娘**：2025年6月に英語版を世界配信。それでも2025年9月時点で課金額の**97%が日本**。海外は3か月で約5,530万ドル、大半は米国。競馬という日本ローカルな前提知識が必要で海外では広がりに限界
- **ブルーアーカイブ**（韓国 Nexon Games 開発）：日本はダウンロードの34%だが収益の**72%**
- **原神**（中国 HoYoverse 開発）：最初から世界向けに作られ、多言語・多機種対応で幅広く遊ばれた本当の世界的ヒット
- → **絵柄は壁にならない。届くかを分けるのは前提知識**。遊ぶ人はアジア全体、お金は日本に集中しやすい
- → 目指すのは「ウマ娘型（日本の前提知識が必要）」ではなく「**原神型（誰でも入れる）**」

## 泣きゲーは今の時代に刺さるか

- 電撃オンラインの2026年夏の「泣きゲー」読者投票で **CLANNAD が1位**。トップ10に AIR、Summer Pockets、リトルバスターズ！と Key 作品が並ぶ。発売から20年以上経っても支持が続く
- 同投票では FF10、ペルソナ3、鳴潮など**アドベンチャー以外も上位** → 今は長大なノベル単体より、**RPG・ソシャゲ・育成の中に泣ける物語が組み込まれる形**が主流（ブルアカのメインストーリーなど）
- 海外：**Spiritfarer**（魂を船で世話して最後にあの世へ送り出す、ほっこり×別れ）が**100万本超**。付喪神の「供養して送り出す」結末と構造がほぼ同じ。OMORI（可愛い×ホラー×泣ける）もカルト的人気
- → **遊びは軽く毎日触れて、物語でしっかり泣かせる**のが今の泣きゲーの形。1話数分の短い物語を積み重ね、最後に大きく泣かせる構成

# 06 世界観・物語の軸（ブレスト段階）

Ryo が「ありかな」と感じた方向性を中心に整理。細部はすべて案。

## 全体を貫く物語の軸（Ryo が良いと感じた方向）

Key 作品（CLANNAD の「光の玉」、AIR の千年続く翼の物語）のように、**全キャラの物語を一本の軸にまとめ、最後に大きな物語へ収束させる**。金継ぎは表現の一つに留め、全体の軸は別に用意する。

### 軸1：九十九年目の家（Ryo が「面白そう」と評価）
- 付喪神は「九十九神」とも書き、百年近く経った物に魂が宿るという言い伝えから
- 受け継いだ古民家は**今年で九十九年目**。百年目を迎える日に、家が**神様になるか、妖怪になるか**が決まる
- 道具たちをどれだけ大切にしたかが、最後の運命を左右する → 期限と緊張感

### 軸2：家そのものが最後の付喪神（Ryo が「ありかな」と評価）
- 道具が一人目覚めるたびに、家の中に**小さな灯**がともる
- すべての灯がそろうと、**家の付喪神（座敷わらし）**が姿を現す
- 「家がずっと見守っていた」という最後の物語へ

#### 座敷わらしについて
- 東北地方に伝わる家の守り神。住みついた家には幸運をもたらし、去ると家が傾くとされる
- **注意：伝承では子どもの姿で語られることが多い** → 以下のどちらかに決める（未決定）
  - A. 子どもの姿のまま、**恋愛対象ではない「家の守り神」**の位置づけ
  - B. 恋愛・エンディングにも関わらせるなら、**大人の姿の「家の神様」**としてアレンジ

### 軸3：道具に残る記憶の持ち主（未決定・ブレスト対象）
- 案A：祖母と家族の何世代かの物語（Ryo は刺さるか半信半疑）
- 案B：**この家に住んできた時代ごとの色々な持ち主たち**（大正・昭和・平成…）の思い出が道具に残っている
- 個別の物語は独立しつつ、集めると「なぜこの家が主人公に託されたのか」が見える形が理想

### 軸4（参考）：縁の糸
- 一人と心を通わせるたびに一本の糸を受け取り、組紐に編み上げると最後の物語が開く

### 組み合わせ案
**九十九年目（軸1）× 家の付喪神と灯（軸2）× 道具に残る記憶（軸3）**
- 九十九年目の古民家を受け継いだ主人公が、眠っていた道具たちと出会う
- 一人ひとりの物語を通じて、家の歴史が少しずつ明かされる
- 目覚めた道具の数だけ灯がともり、百年目の日、家の付喪神が現れる
- 妖怪ルートの子たちも「家の影の部分」として最後の物語に関わる。妖怪ルートを救ったかどうかでも結末が変わる

## 期限のある物語と「続けるゲーム」の両立（案）

Ryo の懸念：「課金してずっとほのぼの続ける」方向とは違うため、期限のある物語とゲームシステムの整合性が取れるか。

### 解決案：本編と「その後の日常」に分ける
- **本編**：九十九年目の一年間。章ごとの進行で、**現実の一年ではなく数か月で遊び切れる長さ**。百年目がクライマックス
- **その後の日常**：家が神様になった後も暮らしは続く。家の守り神が新しくやってきた物や季節の道具を迎え入れ、付喪神が増えていく。季節イベント・追加キャラはここに足す

### 参考：Stardew Valley
- 亡くなったおじいさんが3年目の初めに現れ、それまでの暮らしを評価する区切りがある。その後もゲームは続き、評価が低くても後からやり直せる

### ルール
- 百年目に灯が少なくても即終わりにしない。家は妖怪側に傾くが、その後も救い直せる（「必ず取り戻せる」ルールと一致）

### 課金との整合
- 見た目・季節の付喪神の追加パック → 「その後の日常」に自然に乗る
- 将来：**別の古い家を舞台にした第二章**の追加販売

## 妖怪ルートの結末（後味よくまとめる）（案）

基本方針：**妖怪化は「罰」ではなく「助けを求めるサイン」**。怖さの奥に寂しさがあり、気づいて応えると救われる。

### 結末のパターン
1. **和解して戻る**：妖怪になった理由（記憶）を知り、望んでいたことをすると付喪神の姿に戻る。一度すれ違ったぶん絆が深まる
2. **金継ぎの姿になる**（Claude の推し）：戻った後も、妖怪だった跡が金色の模様として残る。妖怪を経た子だけの特別な姿。「傷ごと大切にする」テーマと直結
3. **妖怪のまま相棒になる**：怖いけど可愛い姿のまま暮らす道。図鑑に神様と妖怪の両方の姿が載り、妖怪ルートが「失敗」ではなく「もうひとつの物語」になる
4. **供養して送り出す**：人形供養・針供養のように、役目を終えた物に感謝して送り出す実在の風習から。小さなお守りを残していく、切ないが温かい別れ
5. **生まれ変わる**：着物が巾着に、割れた器が箸置きに。同じ魂が新しい姿で宿る（「もったいない」の精神、新キャラとしても登場可）

### 例：傘
置き忘れが続く → 唐傘お化けになり、雨の夜に玄関の外でじっと待っている（一番怖い場面）→ 昔誰かに貸したまま返ってこなかった時と同じ寂しさを抱えていたとわかる → 雨の中を一緒に歩くと元の姿に戻り、骨の一本に金の継ぎ跡が残る。「迎えに来てくれて、ありがとう」

### 後味をよくするルール
- プレイヤーを責めすぎない。妖怪側も「気づいてくれてありがとう」で終わる
- 妖怪化は必ず取り戻せる。プレイヤーが選ばない限り永遠に失われない
- 怖さは一番盛り上がったところで寂しさに反転させ、そこで泣かせる
- 結末のあとに短い場面（その子がまた使われている様子など）

調査日：2026年10月17日。数字は出典の時点のもの。

## 最大の先行事例：Date Everything!

- 2025年6月17日発売（PC / Switch / PS5 / Xbox）。開発 Sassy Chap Games（声優が立ち上げたスタジオ）、販売 Team17
- 特殊なメガネで家の中の物と恋愛できる。攻略対象100体、フルボイス
- **販売：2025年8月時点で50万本以上**。OpenCritic で批評家の85%が推薦 → **商業的には成功作**
- ヒットの原動力：**豪華な有名声優陣**とコメディ（Matt Mercer、Laura Bailey、Troy Baker など）。個人では真似できない
- **「Realization（実体化）」の仕組みがある**：関係を深め、ストーリーを終え、必要なステータスを満たすと物が実体化する。全員実体化がトゥルーエンド条件
  → 「最後に人間になる」骨格自体は先行されている。本作は**変化の過程**と**お世話による条件**で差をつける

### 批判されている点（＝本作のチャンス）
- 100体いるせいで質より量。ゲーム内30日目あたりで飽きるという声
- 全員と話さないと進めない強制感、会話スキップなし
- PC Gamer：「恋愛シミュレーションというジャンルを理解していない」。図鑑にID番号、親密なやりとりがコンプリート作業になっている
- 攻略対象の男女比が男性寄り
- Ryo の所感：**キャラが可愛くない**

## 市場の状況

- 単純なハイパーカジュアルは頭打ち。**2025年にアプリ内課金を伸ばしたのはハイブリッドカジュアルだけ**（20%増の42億ドル、特にパズル系）
- 広告収益の比率は地域差が大きい（2026年1〜5月、米国のモバイルゲーム収益の約22%、インドは70%）→ 英語圏・東アジアでは広告だけに頼らない
- AI普及で「独自性」がより重視される流れ
- 出典：https://app.cinevva.com/guides/casual-games-trends-2026 / https://wnhub.io/news/other/item-49726

## インディーゲームの収入実態（Steam）

- 収入は極端な一部が総取り。2025年のSteamの中央値は約249ドルという集計も（集計方法で数百〜数千ドル）
- 自主販売インディーの上位25%で売上2万6千ドル前後
- 開発者純収益5万ドル以上は全体の約10〜15%
- チームの3作目平均は約20.9万ドル、デビュー作は約12万ドル → 本数を重ねると伸びる
- 出典：https://ziva.sh/blogs/indie-game-revenue / https://www.steampageanalyzer.com/blog/indie-game-sales-statistics

## 業界未経験・副業からヒットした先行事例

年齢は公表されていない人が多いため「30代後半から」とは断定できないが、**ゲーム業界の外で本業を持ちながら副業・趣味でヒットを生んだ例**は多い。

| 作品 | 作者 | 背景 | ヒットのきっかけ |
|---|---|---|---|
| Vampire Survivors | ルカ・ガランテ（Poncle） | イタリア出身。ロンドンで英語の壁により業界に入れず、マクドナルドやギャンブル業界で働く。**週末の副業**で制作 | Steam 早期アクセス当初は同時プレイ12人ほど。本人は諦めかけていたが、人気YouTuber（SplatterCat）の動画で翌月同時プレイ5万人超。6日後に会社設立 |
| Balatro | LocalThunk | 数年間プログラマーとして勤務。商業リリース経験なし。**有給休暇で試作を始めた副業** | 「Steamで10本売れれば」程度の想定が、配信者に見つかり100万本以上。Steam好評率97% |
| ひぐらしのなく頃に | 竜騎士07 | 地方公務員として働きながら**同人ゲーム**として制作したとされる。絵も自作 | 物語の力で爆発的ブーム。ホラー×泣きの組み合わせは本作にも近い |

### 共通点
- 本業があり、**副業として始めた**
- 最初は誰にも見られていなかったが、**配信者・実況者に見つかって一気に広がった**
- 技術や絵の上手さより、**ひとつの強いアイディアと体験**で勝負した

※成功した一握りの例。同じように作って売れなかった人の方がずっと多い

## バズるゲームの型（8層）— 別企画にも使える汎用フレーム

1. **ワンアイディア**：「既存ジャンル × ひとつのひねり」を一言で
2. **触感**：入力に即反応し、触るだけで気持ちいい
3. **爽快感**：消える・変わる瞬間に音・揺れ・光・ボイスを重ねる
4. **手軽さ**：3秒でルール理解、片手、短時間
5. **「もう1回」設計**：惜しかった・次はいける
6. **キャラ・萌え**：愛着
7. **シェア装置**：実況映え、結果を画像化、失敗が笑える
8. **継続フック**：デイリー、コレクション

# YouTube チャンネル（英語・知的エンタメ）— サイドプロジェクト

> **付喪神ゲームとは別のプロジェクト。** このフォルダの中だけで完結させ、ゲーム側のドキュメント（`docs/`、`PLAN.md`）とは混ぜない。
> 後でプロジェクトを分けるときは、このフォルダをそのまま新しいリポジトリのルートにする。

## 何のプロジェクトか

日本人の視点・マニラでの海外勤務経験・IT とビジネスの専門性を組み合わせ、
世界の文化・仕事・社会・テクノロジーを英語で考察する YouTube チャンネル（顔出しなし、アバター＋自分の声ベースの AI ナレーション）。

核（原メモより）：

> 日本について英語で説明するチャンネルではなく、日本人ならではの経験と視点を通して、世界について考えるチャンネルを作る。

- 状態：企画・コンセプト検討段階（2026-10-24 時点）
- チャンネル名：未決定（案：Japanese Lens / World Through Japanese Eyes など）

## 付喪神ゲームとの関係

- 基本は無関係。ルール・判断ポイント（`.claude/rules/`）は、このリポジトリにある間は同じものに従う
  （特に「外部への投稿は Ryo が手で行う」「有料サービスを新しく使うときは止まって聞く」）
- 接点になりうるもの（案）：付喪神の世界観を題材にした動画（`ideas/video-ideas.md` の B-3）、
  ゲーム用に作った音声・動画のツール（`tools/`）の流用。流用する場合は、分割のときにツールの扱いを決める

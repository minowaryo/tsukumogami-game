## 判断A 案：年末編で制作の流れを検証する（Ryo の OK 待ち）

**作るもの**：Shorts 1 本（縦長 1080x1920、45〜60 秒）"Christmas starts in September?!"（`ideas/s1-year-end.md` 3 章）。
台本 → ナレーション → 柴犬アバター＋図解のカード → 字幕 → 書き出し、を一通り通し、各工程の時間と費用を測る。

Shorts から始める理由：今ある組み立てツール（`tools/video/compose.mjs`）は 9:16 前提で、そのまま土台にできる。
長尺の横長はツールの作り直しが要るので、流れを確かめてからにする。

**完了条件（触って確かめられる形で）**

- [ ] 仕様ファイルからコマンド 1 つで、45〜60 秒・1080x1920 の MP4 が書き出せる
- [ ] 英語のナレーションと英語の字幕が合っている（ずれが目で分からない程度）
- [ ] 柴犬が 2 種類以上の表情（または口の開閉）で、話に合わせて切り替わる
- [ ] 画面が 3 回以上変わる（比較カード、カレンダーの図、問いのカードなど）
- [ ] 台本が `video-review` の台本の関門を通っている（M は Ryo の実体験に置き換え済み）
- [ ] 工程ごとの時間と費用の記録がある（1 本あたりの見積もりの材料）

**やらないこと**：YouTube への投稿、声のクローン、長尺・横長、チャンネル名・ロゴ、新しい有料ツールの契約。

**分かっている穴**：今の組み立てツールは「元の映像 1 本＋効果音＋字幕」の合成だけ。画像（アバター・カード）を時間で並べる機能と、
ナレーションの音声を入れる機能がない。ここを足すのが検証の実装の中心になる。
ゲーム側の `tools/` を直すか、このフォルダの中に分けて作るかは、分割のしやすさを考えて決める（案：このフォルダの中に作る）。

**決めてほしいこと（Ryo）**

1. **ナレーションの声**：(a) ElevenLabs の既存の英語の声（キーの取得が要る。有料プランなら止まる条件）／(b) Ryo が自分で英語を録音する／
   (c) 検証の間だけ Windows に入っている読み上げ音声で仮置き（費用ゼロ、品質は低い）。案：(c) で流れを通し、(a) か (b) に差し替える
2. **柴犬の画像の出どころ**：誰が・何で作った画像か（AI 生成ならどのサービスか）。商用に使えるかが変わる（止まる条件 6）。
   表情の差分を ComfyUI で作るか、元の作り方で作るか
3. **費用の上限**：このチャンネルの月の上限（ゲーム側の 40 ドルとは別）
4. **ツールの置き場所**：上の「分かっている穴」の案でよいか

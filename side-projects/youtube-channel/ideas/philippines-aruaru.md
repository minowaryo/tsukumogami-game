# フィリピンあるある（受け皿）

> Ryo が後で追加する。1 ネタ 1 行で、まずは雑に書いてよい。肉付けは AI と一緒に行う。
> 動画にするときは `../guidelines/guardrails.md` の **R1（人を笑わない。笑うのは状況）** と **鏡の型**を必ず通す。

## 書き方

| 列 | 中身 |
|---|---|
| あるある | 見た・体験したこと（1 行） |
| 場面 | いつ・どこで（職場／街／家／店など。個人や会社が分からない書き方で） |
| 日本の鏡 | 同じテーマで、日本側の「変なところ」（AI が案を出してもよい） |
| 解釈 | なぜそうなるのか（仕組み・環境の目で） |
| 形式 | Shorts／長尺の一部／長尺 1 本 |
| つながる企画 | `video-ideas.md` の ID（例：B-5） |

## ネタ

| # | あるある | 場面 | 日本の鏡 | 解釈 | 形式 | つながる企画 |
|---|---|---|---|---|---|---|
| 1 | | | | | | |

## まとめ方の案

- 1 ネタ → Shorts 1 本（`guardrails.md` 3-2 の構成）
- 同じテーマのネタが 3〜7 個たまったら → 長尺 1 本（例：「時間」「職場」「食」「家族」「お金」）
- 反応がよかった Shorts のテーマを、長尺の企画（`video-ideas.md`）に昇格させる
